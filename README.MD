# Yupoo Plus - Userscript for making Yupoo look better!
![Screenshot](/media/CAT_ALL.png)

I never really liked how annoying Yupoo looked with the small images, so I made a userscript to clean it up.

**NOTE:** This has been developed & tested using ***Firefox*** / ***Tampermonkey***, so if there are any errors with other Chromium-based browsers or GreaseMonkey, please raise an [issue](https://github.com/Noklef/yupoo-plus/issues)!

## Features
- Redesigned UI
- ***Proper*** dark mode (*NOTE: this may clash with extensions like Dark Reader*)
- 5 different image layouts: `Editorial`, `Dense`, `Info Cards`, `Masonry`, and `Showcase`
- Resizable cards (No more browser zoom necessary)
- Full width toggle
- Price parsing from titles
- ~~Endless Scroll~~ Not yet... kinda broken

## How to install
- Install the [Tampermonkey](https://www.tampermonkey.net/) extension to your browser.
- Click this link, and it will open up in Tampermonkey:
  - [https://github.com/Noklef/yupoo-plus/raw/refs/heads/main/src/yupoo-gallery-ui.user.js](https://github.com/Noklef/yupoo-plus/raw/refs/heads/main/src/yupoo-gallery-ui.user.js)
- Click `Install`
- Navigate to any Yupoo URL, and you'll see a `Yupoo Plus` window in the bottom right
